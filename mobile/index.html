Control por gestos

Usa las dos manos: con una movés el índice para mover el cursor de tu PC y juntás el pulgar y el índice (pellizco) para hacer clic o arrastrar. Con la otra hacés puño cerrado y lo movés arriba/abajo para hacer scroll. La cámara se apaga sola si salís de esta pestaña o tocás "Desactivar".
