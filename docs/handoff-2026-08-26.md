# ATLAS — Notas para retomar (sesión del 26 ago 2026)

## Cómo levantar todo de nuevo (si se cerró todo al apagar la PC)

```powershell
# Terminal 1 — backend (HTTPS si existe certs/dev-cert.pem)
cd backend
python run.py

# Terminal 2 — cliente de escritorio (wake word "Atlas")
cd desktop
python run.py          # usa el Python del sistema (C:\Python313), no tiene venv propio

# Terminal 3 — PWA móvil
cd mobile
python serve.py

# Terminal 4 — dashboard (solo esta PC)
cd dashboard
python serve.py
```

Contraseña de login en todos: `admin123`.

**Primera vez en un navegador nuevo (o si el backend regenera el
certificado)**: entrar una vez a `https://127.0.0.1:8000/api/v1/system/health`
directo y aceptar la advertencia de certificado ("Avanzado" → "Continuar de
todas formas"). Sin ese paso, el dashboard y el desktop fallan con errores
de conexión silenciosos.

## Qué se hizo en esta sesión

- **Dashboard (Fase 9) construido**: la carpeta `dashboard/` estaba vacía
  pese a que la documentación la daba por terminada — se detectó y se
  construyó (sidebar, orbe de voz con visualizador real de Web Audio API
  tanto al grabar como al escuchar la respuesta, anillos de CPU/RAM/Disco,
  vistas de dispositivos/rutinas/notificaciones/memoria/actividad).
  Confirmado funcionando en vivo.
- **Bug de HTTPS en el cliente de escritorio**: `desktop/` seguía
  apuntando a `http://` después de que el backend pasara a HTTPS-only —
  fallaba en silencio (parecía "el wake word no anda" pero la ventana ni
  abría). Corregido.
- **Bug de HTTPS en el dashboard**: mismo problema, `app.js` asumía el
  mismo esquema que su propia página. Corregido con detección automática
  (prueba `https://` y `http://` al cargar).
- **Control por gestos (celular controla el mouse de la PC)**: rediseñado
  a dos manos — derecha mueve el cursor (nudillo del índice, no la punta)
  y hace clic con pellizco; izquierda hace scroll con puño cerrado.
  Umbrales de pellizco y de detección de puño recalibrados. Cursor y clic
  confirmados funcionando; **scroll y detección simultánea de dos manos
  quedaron sin confirmar en vivo** (ver pendientes).
- Documentación actualizada: `README.md`, `docs/architecture.md`,
  `docs/pending-manual-tests.md`, `docs/future-gesture-control.md`
  (marcado como superado por el diseño real implementado).
